## Summary
`.gitignore` only excludes select `.idea/` subpaths (`caches`, `libraries`, `modules.xml`, `workspace.xml`, `navEditor.xml`, `assetWizardSettings.xml`), but several `.idea/*.xml` files (`codeStyles/Project.xml`, `compiler.xml`, `encodings.xml`, `gradle.xml`, `jarRepositories.xml`, `misc.xml`, `vcs.xml`) are tracked in git.

## Current Feature
N/A — repo hygiene.

## Current Behavior

## Value Proposition
Minor, but reduces unrelated diff noise in future PRs.
