# 🔧 ENHANCEMENT: Stop committing `.idea/*.xml` project files

## Meta
- **ID**: ENH-016
- **Type**: Enhancement
- **Status**: new
- **Created**: 2026-09-19
- **Breaking**: No

## Summary
`.gitignore` only excludes select `.idea/` subpaths (`caches`, `libraries`, `modules.xml`, `workspace.xml`, `navEditor.xml`, `assetWizardSettings.xml`), but several `.idea/*.xml` files (`codeStyles/Project.xml`, `compiler.xml`, `encodings.xml`, `gradle.xml`, `jarRepositories.xml`, `misc.xml`, `vcs.xml`) are tracked in git.

## Current Feature
N/A — repo hygiene.

## Current Behavior
IDE-specific project files are committed, which can cause noisy diffs and per-contributor IDE-state churn.

## Desired Improvement
Decide which `.idea/` files are intentionally shared (e.g. `codeStyles` for consistent formatting) vs which should be untracked, update `.gitignore` accordingly, and `git rm --cached` the rest.

## Value Proposition
Minor, but reduces unrelated diff noise in future PRs.

## Acceptance Criteria
- [ ] `.gitignore` updated to reflect the intended policy
- [ ] Unwanted tracked `.idea/*.xml` files removed from git tracking (not deleted from disk)
