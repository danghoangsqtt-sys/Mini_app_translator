# 🐛 BUG: Vendored GraphView library has an unimplemented branch that throws

## Meta
- **ID**: BUG-012
- **Type**: Bug
- **Status**: new
- **Severity**: Medium
- **Created**: 2026-09-19
- **Affected**: `tools/gui/graph/GridLabelRenderer.java:608`

## Summary
The vendored copy of the GraphView charting library (Jonas Gehring, Apache-2.0, copy-pasted into the app package rather than pulled as a dependency) has a branch that does `throw new IllegalStateException("Not yet implemented")` for non-manual Y-axis bounds on the second scale.

## Actual Behavior
If any code path (current or future) enables auto-bounds on the second Y-axis scale of a graph using this component, the app crashes with an unhandled `IllegalStateException`.

## Expected Behavior
Either implement the missing auto-bounds calculation for the second scale, or guard the UI so that configuration is never reachable, with a clear comment explaining why.

## Steps to Reproduce
1. Find/build a graph screen (e.g. usage/consumption charts in `api_management`) that uses a second Y-axis scale.
2. Enable auto-bounds (non-manual) on that second scale.
3. Observe the crash.

## Error Messages
`java.lang.IllegalStateException: Not yet implemented`
