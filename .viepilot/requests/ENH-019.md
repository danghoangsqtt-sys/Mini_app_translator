# 🔧 ENHANCEMENT: Modernize the Mini Conversation UI and accessibility

## Meta
- **ID**: ENH-019
- **Type**: Enhancement
- **Status**: planned (Phase 5, tasks 5.3-5.6)
- **Created**: 2026-09-20
- **Breaking**: No intended behavior change

## Summary
The UI uses a 2020 AppCompat theme, hardcoded light surfaces and green palette, custom toolbar/layout patterns, and no night resources. Static inspection found 14 interactive image controls and all 14 lack `contentDescription`; several visible icon controls are 24dp, below Android's recommended 48dp touch target.

## Desired Improvement
Refresh the existing Views UI with Material Components/Material 3 styling after the Android toolchain upgrade. Build a coherent blue/cyan/green visual system from the supplied icon, support light/dark themes, improve screen hierarchy, and fix accessibility without rewriting business logic or moving to Compose in the same phase.

## Acceptance Criteria
- [ ] Semantic color/type/spacing tokens replace screen-level hardcoded colors where practical
- [ ] Light and dark themes render all primary screens with readable contrast
- [ ] Interactive controls provide at least a 48×48dp focus/touch area
- [ ] Every actionable icon has a localized accessible label; decorative images are explicitly ignored
- [ ] Text scales without clipping at 200%; layouts work on compact and large screens
- [ ] Conversation, WalkieTalkie, pairing, onboarding, API key, and settings flows preserve their existing behavior
- [ ] Visual/device QA covers API 23, 31, 34, and 36 plus TalkBack smoke testing
