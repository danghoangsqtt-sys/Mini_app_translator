# 🔧 ENHANCEMENT: Upgrade the 6+ year old Android build toolchain

## Meta
- **ID**: ENH-011
- **Type**: Enhancement
- **Status**: in_progress (Phase 3 Cluster A implemented/static PASS; device and release QA pending)
- **Created**: 2026-09-19
- **Breaking**: Yes (build tooling upgrade, likely requires source changes for API deprecations)

## Summary
The original audit found AGP 3.6.1, Gradle 5.6.4, and API 29. Phase 3 Cluster A now uses AGP 8.13.2, Gradle 8.13, JDK 17, and compile/target SDK 36. Physical-device and release evidence remain pending, and Task 3.3 dependency refresh is intentionally deferred.

## Current Feature
The entire app's build configuration.

## Current Behavior
Likely fails to build on current Android Studio without manual intervention; does not meet current Google Play target-API requirements (Play Store enforces a minimum `targetSdkVersion` tied to the current year, well above 29).

## Desired Improvement
Upgrade AGP, Gradle wrapper, JDK, `compileSdk` and `targetSdk` to a documented API 36-compatible combination. Remove obsolete explicit Build Tools pinning, replace `jcenter()`, add the required `namespace`, and review the old protobuf plugin/configuration as part of the staged migration. Resolve platform behavior changes in `BUG-006`, `BUG-013`, `BUG-014`, and `BUG-015` in the same phase.

## Value Proposition
Without this, the app cannot be updated on the Play Store and increasingly can't be built by contributors on current tooling.

## Acceptance Criteria
- [ ] App builds cleanly on a current Android Studio / AGP / Gradle version
- [ ] `compileSdk` and `targetSdk` are API 36 and meet the 31 August 2026 Play requirement
- [ ] JDK, AGP, Gradle, protobuf plugin, and Android Studio versions are documented and mutually supported
- [ ] `jcenter()` is removed and dependency resolution succeeds from supported repositories
- [ ] Existing functionality regression-tested after the upgrade (this is the highest blast-radius change in the backlog — plan for a dedicated phase, not a quick patch)

## Implementation Notes
Implemented as Phase 3 planning. Tasks 3.1, 3.2, 3.4, and 3.5 must ship together because the target bump activates their platform requirements.
