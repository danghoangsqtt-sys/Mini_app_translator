## Summary

Make Mini Conversation usable without asking ordinary users to create a Google Cloud project, enable billing, or import a service-account JSON file. The default path must use supported Android/Google on-device capabilities; the existing Cloud implementation may remain only as an explicit legacy/advanced option during migration.

## Product decision

- Default: Android SpeechRecognizer + ML Kit Translation + Android TextToSpeech.
- Prefer on-device speech recognition when the device exposes it; use the system recognizer fallback with truthful disclosure when it does not.
- Never scrape `translate.google.com/m` in production.
- Never embed a shared Google Cloud credential in the APK.
- A future managed Cloud backend is optional and outside Phase 9 unless separately approved.

## Acceptance criteria

- [ ] First launch does not require a Google Cloud key or billing setup.
- [ ] Translation models can be downloaded, used offline, inspected, and deleted.
- [ ] Speech-recognition capability is detected without crashing on API 23–36.
- [ ] Conversation and WalkieTalkie use engine interfaces instead of constructing Cloud clients directly.
- [ ] Missing models, missing recognizers, denied microphone permission, and offline/network failures produce recoverable UI states.
- [ ] Legacy Cloud mode is opt-in and no service-account key is bundled with the APK.
- [ ] Automated and device gates pass before any release is marked ready.

## Non-goals

- Wi-Fi Hotspot transport.
- Java package/applicationId migration.
- Copying AGPL code from `D:\DataAdmin\vp-pdf`.
- Shipping an undocumented Google Translate web endpoint.
