# BUG: Android 12+ Conversation notification PendingIntent crashes the app

## Meta

## Summary

After two physical Android phones connected, both apps terminated and every relaunch replayed Conversation. API 36 reproduction showed Android rejecting the foreground-notification `PendingIntent` because no mutability flag was supplied.

## Root cause

`VoiceTranslationActivity` created the Conversation foreground-notification `PendingIntent` without `FLAG_IMMUTABLE` or `FLAG_MUTABLE`. Android 12+ requires explicit mutability, so notification construction threw before the service could stabilize.
