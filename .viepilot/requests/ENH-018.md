## Summary
The repository is branded “Mini App Translator”, the installed app is still “RTranslator”, and the requested product name is “Mini Conversation”. Branding also remains in English/Italian strings, privacy documents, notification copy, links, and FileProvider authority.

## Desired Improvement
Use “Mini Conversation” consistently in user-visible product surfaces while preserving the existing application ID and Java package during the first rebrand release. Replace launcher resources from `images/icon.png`; treat `images/icon.ico` as a desktop/reference asset only.

## Acceptance Criteria
- [ ] `@string/app_name` and user-visible brand copy use Mini Conversation in all locales
- [ ] README, privacy documents, notification text, and ViePilot metadata distinguish the new product name from upstream attribution
- [ ] `applicationId` and package names remain stable unless a separate migration decision is approved
- [ ] Launcher icon includes legacy density assets, adaptive foreground/background, round icon, and a safe mask preview
- [ ] Manifest declares both `android:icon` and `android:roundIcon`
- [ ] Upstream RTranslator attribution and Apache-2.0 notices remain intact

## Implementation Notes
Use `images/icon.png` (1254×1254, ARGB) as the source. Do not copy the finished composite directly into the adaptive foreground at full bleed; resize it into the adaptive safe zone so OEM masks do not crop the speech bubbles.
