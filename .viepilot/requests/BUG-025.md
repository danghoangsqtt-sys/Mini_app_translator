## Summary

`SettingsFragment.notifyMissingGoogleTTSDialog()` stores the event under `command`, while its handler switches on `type`. If the missing-TTS branch is reached, it is therefore interpreted as the default integer value instead of `ON_MISSING_GOOGLE_TTS`. The `MISSING_GOOGLE_TTS` failure case also falls through to the generic error callback.
