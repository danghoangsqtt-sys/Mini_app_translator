# 🐛 BUG: Launcher activity lacks explicit `android:exported`

## Meta
- **ID**: BUG-014
- **Type**: Bug
- **Status**: planned (Phase 3, task 3.4)
- **Severity**: High
- **Created**: 2026-09-20
- **Affected**: `app/src/main/AndroidManifest.xml:35-46`

## Summary
`LoadingActivity` owns the launcher `<intent-filter>` but does not declare `android:exported`. Android 12+ requires an explicit value for every component that has an intent filter. Once the app targets a modern API level, the current manifest prevents installation/build packaging for Android 12+.

## Actual Behavior
The launcher activity has a `MAIN`/`LAUNCHER` filter with no `android:exported` attribute.

## Expected Behavior
Declare `android:exported="true"` for the launcher activity and explicitly declare `false` for internal components where applicable.

## Acceptance Criteria
- [ ] Launcher activity declares `android:exported="true"`
- [ ] Internal activities/services/providers are reviewed and explicitly kept non-exported unless an external contract requires otherwise
- [ ] Manifest merger report is reviewed after the dependency/toolchain upgrade
- [ ] APK installs and launches on Android 12+ with target API 36
