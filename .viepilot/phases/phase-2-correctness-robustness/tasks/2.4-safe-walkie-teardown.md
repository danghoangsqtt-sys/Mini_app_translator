## Plan

Track each call to `bindService`, not a successful connection callback or `bindService` return
value. Android's `Context.bindService` reference requires a matching `unbindService` even when
the bind call returns `false`. Give each recognizer connection its own attempt counter; consume
one count before every matching unbind call so partial bind and repeated start/stop release the
same number of registrations that were attempted.

`onDestroy` must separately attempt communication shutdown, each tracked unbind, and
`super.onDestroy`, logging cleanup exceptions but never using `IllegalArgumentException` as the
binding-state decision. The nearby `onStartCommand(null)` dereference is documented as a separate
follow-up because it is not a binding-lifecycle repair.

## File-Level Plan

| File | Change | Why |
|---|---|---|
| `WalkieTalkieService.java` | Record each bind attempt before invoking `bindService`; release each recorded attempt during teardown. | Matches Android's bind/unbind contract without treating return value or callback delivery as registration state. |
| `BindingAttemptTracker.java` | Provide a small per-connection counter with safe attempt consumption. | Makes partial and repeated binding state deterministic and JVM-testable. |
| `BindingAttemptTrackerTest.java` | Exercise no bind, one connection, false-result attempt, both connections, and repeated attempts. | Covers the lifecycle states with a controlled test harness. |
| `WalkieTalkieServiceBindingSourceTest.java` | Detect the old unconditional paired unbind sequence in the production service. | Records a focused fail-before-fix regression signal tied to the service lifecycle path. |
| `BUG-010.md` and this task file | Correct reproduction contract, record API evidence, adjacent null-intent finding, and verification. | Keeps the tracked defect precise. |
| `CHANGELOG.md` | Add the lifecycle cleanup fix under Unreleased. | Makes the behavior change traceable. |
