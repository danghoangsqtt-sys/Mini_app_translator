# Task 3.1 — Upgrade Android toolchain and target API 36

## Request

`ENH-011`; integrated change with tasks 3.2, 3.4 and 3.5.

## Paths

```text
build.gradle

```

## Plan

Start with a compatibility spike using AGP 8.13.2, Gradle 8.13, JDK 17 to run Gradle, `compileSdk`/`targetSdk` 36, `minSdk` 23, and Java 8 source/target compatibility. Add the required namespace, migrate repositories off `jcenter()`, remove explicit `buildToolsVersion 28.0.3`, and let AGP select its supported default. Run manifest merger plus protobuf generated-source/compile smoke tests before treating this candidate as viable. Candidate protobuf Gradle plugin 0.10.0 is part of that spike, not a completed dependency decision. Integrate 3.2/3.4/3.5 before landing the target bump; compare merged manifests and test old/new Android behavior. Avoid Phase 5 UI/rebrand work.

Never commit `org.gradle.java.home`, a personal JDK path, debug-keystore path, signing password, keystore, or other signing secret. Configure JDK 17 through the execution environment or approved CI/IDE configuration.

## Done when

- Compatibility spike proves AGP/Gradle/JDK/protobuf code generation together before the wider dependency refresh.
- Supported clean build and `testDebugUnitTest lintDebug assembleDebug assembleRelease` pass using JDK 17 to run Gradle.
- API 36 target, namespace, repository migration, tool versions, manifest merger, and compatibility decisions are documented.
- Integrated permission/component/service/device checks from 3.2/3.4/3.5 pass in the same change.
