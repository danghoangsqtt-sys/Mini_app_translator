## Source

The audit found a stale Phase 3 worktree, four detached QA worktrees, 358 tracked files under unrelated `.agents/skills/`, 13 tracked `.idea` files, and 36 local commits not yet persisted to `origin`.

## Plan

Declare `master` in the primary worktree as the only release source of truth. Compare the two unique Phase 3 branch commits with current `master` and document why they are superseded or identify any exact hunk that must be preserved; do not merge/cherry-pick the branch wholesale. Ask the maintainer to decide whether `.agents/skills/` belongs in this app repository and which `.idea` files are intentionally shared. Apply only the approved untracking/ignore policy. Inventory detached/stale worktrees and mark them removable only when clean and when their commits remain reachable from a named branch/tag. Do not delete directories or Git worktrees without the explicit maintainer decision required at execution time.

## Done when

- `master` is documented as canonical and the stale Phase 3 branch has a written disposition.
- `.agents/skills/` and `.idea` each have an explicit keep/untrack policy reflected in Git.
- No unique work is lost; every removable worktree is clean and its commit is preserved.
- The release diff contains no unrelated project payload.
