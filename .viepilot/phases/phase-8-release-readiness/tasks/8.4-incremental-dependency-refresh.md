## Plan

Refresh one dependency family per checkpoint, reviewing official migration notes and resolved dependency graphs before each change. Start with test/support libraries that do not change runtime behavior, then Room with schema export/migration verification, Nearby/Bluetooth-facing libraries, and finally gRPC/Protobuf/Auth/JWT. Run unit tests, lint, debug assembly and focused instrumentation after every family. Compare against Task 8.3 device evidence after behavior-sensitive upgrades. Never combine unrelated major upgrades in one commit, silently reset the Room database, mass-suppress lint, or accept a TLS/security warning without proving it is unreachable or removed.

## Done when

- Each upgraded family has its own reviewable commit and compatibility notes.
- Room schema/persisted data survives upgrade testing or has an explicit migration.
- Conversation discovery/connection and cloud speech/translation paths match the baseline.
- Dependency/security warnings have been removed or have a documented, evidence-backed disposition.
- Phase 3 Task 3.3 and `ENH-012` are updated with actual verification evidence.
