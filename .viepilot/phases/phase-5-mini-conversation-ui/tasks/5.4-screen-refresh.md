## Plan

Depends on 5.3 (semantic theme attrs must exist first). Retain every existing `@+id/...` view ID.

- **General sweep, all 32 layout files**: replace hardcoded surface/background/text colors (`#FFFFFF`, `#212121`, etc.) with `?attr/colorSurface`, `?attr/colorOnSurface`, `?attr/colorBackground`, `?android:attr/textColorPrimary` as appropriate to the element's role.
- **Onboarding** (`fragment_notice.xml`, `fragment_user_data.xml`): `Button` → `com.google.android.material.button.MaterialButton`, `CheckBox` → `com.google.android.material.checkbox.MaterialCheckBox`, 16dp side padding, `?attr/colorPrimary` instead of hardcoded color.
- **Pairing** (`fragment_pairing.xml`): device rows → `com.google.android.material.card.MaterialCardView` with 2dp elevation; empty state shows an icon + "searching for devices" text (new string resource) instead of a blank list; search/cancel controls sized to at least 48×48dp.
- **Conversation** (`fragment_conversation.xml`): 16dp corner radius on message bubbles, `?attr/colorPrimaryContainer` for sent / `?attr/colorSurface` for received, a clear source→target language header, and a 56dp `FloatingActionButton` microphone action in `?attr/colorSecondary`.
- **WalkieTalkie** (`fragment_walkie_talkie.xml`): two visually distinct language regions, a light pulse animation while listening (new `Animator`/`AnimatedVectorDrawable` or `ObjectAnimator` on the mic indicator), larger translation-result text size.
- **API/settings** (`fragment_credit.xml`, `activity_credit.xml`, `activity_settings.xml`): `MaterialCardView` groups separating credential setup / usage stats / pricing info (keep the existing `GraphView` untouched); `activity_settings.xml`'s `PreferenceScreen` grouped into `PreferenceCategory` headers (Language, Audio, Privacy, About).

## Done when

- All 6 named screens visually reflect the refresh in both light and dark theme without altering existing view IDs or Java-side logic.
- `./gradlew testDebugUnitTest assembleDebug` succeeds after the change.
