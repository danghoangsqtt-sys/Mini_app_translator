# Task 5.5 — Accessibility and responsive layout

## Requests

`ENH-019`

## Paths

```text
app/src/main/res/layout/*.xml
app/src/main/res/values/strings.xml
```

## Plan

Depends on 5.4 (avoids re-touching the same layout lines twice).

- Grep every `layout/*.xml` for `<ImageView`/`<ImageButton` without a sibling `android:contentDescription` attribute; add one sourced from a new/existing string resource (never a hardcoded literal) describing the control's action or content. Track count against the known baseline of 14.
- Grep interactive elements (`Button`, `ImageButton`, icon-only `View`/`FrameLayout` click targets) with an explicit `layout_width`/`layout_height` below 48dp; add `android:minWidth="48dp"` / `android:minHeight="48dp"`, including the 24dp pairing search/cancel control.
- Spot-check contrast: text on a `colorPrimary`/`colorPrimaryVariant` background must use `colorOnPrimary`; text on `colorSurface` must use `colorOnSurface`.

## Done when

- No `ImageView`/`ImageButton` in `layout/` lacks `android:contentDescription`.
- No interactive element remains under 48×48dp.
- `./gradlew testDebugUnitTest assembleDebug` succeeds.
