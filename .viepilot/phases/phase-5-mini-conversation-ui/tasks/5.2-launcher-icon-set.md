## Plan

- Derive a clean circular master from `images/icon.png` (1254×1254 RGBA) by center-cropping and applying a hard circular alpha mask, discarding the noisy glow/splash halo outside the main circle so small launcher sizes stay crisp. Resize that master (Lanczos) to mdpi(48)/hdpi(72)/xhdpi(96)/xxhdpi(144)/xxxhdpi(192) for `ic_launcher_round.png` (full-bleed circle), and a ~6% inset version of the same master for legacy `ic_launcher.png` at the same five densities, replacing the existing files.
- Remove the now-superseded per-density `mipmap-*/ic_launcher_foreground.png` files (5 files) — the adaptive icon moves to a single `drawable/` foreground/background/monochrome trio referenced from `mipmap-anydpi-v26/`.
- Redraw a simplified flat "two chat bubbles" mark (white bubble with bold `A`, mint/teal bubble with `文`) as `drawable/ic_launcher_foreground.png`, centered in the 66×66dp safe zone of a 108×108dp canvas, transparent elsewhere. A flat redraw (not a photographic crop) is used because the source's bubble glyphs share hue with its own background gradient, making automated background removal unreliable; the flat mark keeps the same silhouette/composition as the source icon.
- `drawable/ic_launcher_background.xml`: vector gradient `#0277BD` → `#00BCD4` covering the 108×108 canvas.
- `drawable/ic_launcher_monochrome.png`: white silhouette sharing the foreground's alpha shape, solid white fill — referenced as the `<monochrome>` layer (a raster silhouette is used instead of hand-authored vector path data, since it can be derived exactly from the foreground's own alpha channel rather than manually traced, and Android accepts any drawable type here).
- Update both `mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml` to reference `@drawable/ic_launcher_background`, `@drawable/ic_launcher_foreground`, `@drawable/ic_launcher_monochrome`.
- Delete the now-unreferenced `values/ic_launcher_background.xml` flat-color resource (only the two `mipmap-anydpi-v26` XML files referenced it, and both are being rewritten).
- Confirm `AndroidManifest.xml` already declares `android:icon="@mipmap/ic_launcher"` and `android:roundIcon="@mipmap/ic_launcher_round"` on `<application>`.

## Done when

- No dangling reference to deleted `mipmap-*/ic_launcher_foreground.png` files or the removed flat-color resource.
- `./gradlew testDebugUnitTest assembleDebug` succeeds.
