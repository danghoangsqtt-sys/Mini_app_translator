- **Date**: 2026-09-20
- **Workflow Version**: 1.1.0 (fw 2.19.0)
- **Project**: RTranslator (Android Java, compileSdk 29, targetSdk 29, AGP 3.6.1, Gradle 5.6.4)
- **Host Environment**: Windows 11 64-bit, Intel Core i7-12700 (12 cores/20 threads), 32GB RAM, Hyper-V/VBS active

## 1. Hiện trạng hệ thống (Reconnaissance)
- **JDK 11**: Đã cài đặt sẵn tại `C:\Program Files\Microsoft\jdk-11.0.32.101-hotspot` (tương thích 100% với Gradle 5.6.4 của dự án).
- **Android SDK**: Đã có tại `C:\Users\Admin\AppData\Local\Android\Sdk` (đã có platform `android-29`, `build-tools 28.0.3`, `platform-tools` với `adb.exe`).
- **local.properties**: Đã tạo và trỏ chính xác vào SDK path.
- **Android Studio IDE**: Chưa được cài đặt.
- **Android Emulator & System Image**: Chưa được tải.

## 2. Các phương án thực hiện (Options)

### Phương án cài đặt Android Studio:
- **Option A (Tự động hóa qua WinGet CLI)**:
  Chạy lệnh: `winget install --id Google.AndroidStudio -e --source winget`
  *Ưu điểm*: Nhanh, chuẩn nguồn Google, tự động cấu hình Start Menu và shortcut.
- **Option B (Tải thủ công từ trang chủ)**:
  Tải file `android-studio-*.exe` từ [developer.android.com/studio](https://developer.android.com/studio) và click Next theo trình cài đặt.

### Cấu hình máy ảo mô phỏng (AVD):
- **Khuyến nghị thiết bị**: Pixel 4 hoặc Pixel 7.
- **Khuyến nghị Android OS Image**: **Android 10.0 (API 29 - "Q") x86_64 (Google APIs hoặc Google Play)**.
  *Lý do*: Dự án RTranslator cấu hình `compileSdkVersion 29` và `targetSdkVersion 29`. Chạy đúng API 29 giúp test môi trường gốc chính xác nhất, tránh các vấn đề xung đột quyền hạn (Scoped Storage, Bluetooth Permissions mới từ Android 12+).
- **Cơ chế tăng tốc phần cứng**: Sử dụng **Windows Hypervisor Platform (WHPX)** (đã kích hoạt sẵn cùng VBS trên Windows 11).
